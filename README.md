## For Learning purposes:

This project demonstrates how to implementthe  **BLoC (Business Logic Component)** pattern in Flutter, using a simple **Counter App**. BLoC is a powerful design pattern that separates the **business logic** from the **UI**, enabling a more modular, testable, and reusable codebase.
